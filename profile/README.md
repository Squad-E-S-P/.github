Squad ESP is a **Squad ESP** overlay built for 100-player tactical matches. See **player boxes**, **skeletons**, **health**, **distance**, and **squad context**, then add **FOB**, **vehicle**, and **objective** markers with team colors and range filters.

- 📏 **Distance readouts** with a configurable cutoff
- 🏗️ **FOB and spawn markers**
- 🚚 **Vehicle indicators** for logistics
- 🎯 **Objective markers** for capture points
- 🎨 **Team colors** and per-element palettes

## 🚀 Why Choose Squad ESP?

Squad is a game of information across a huge map. The overlay keeps infantry boxes readable at range and adds FOB, vehicle, and objective context that plain player ESP leaves out. Filters cut everything beyond the fight you are in.

Each element toggles independently, so a command layout and a frontline layout can coexist as profiles.

## 🎮 Why Use It?

- **Read fights** across open ground
- **Track logistics** with vehicle markers
- **Locate FOBs** during pushes
- **Keep a clean HUD** with range filters
- **Switch layouts** with saved profiles

## 🧩 Quick Start

1. Launch **Squad** and open the ESP panel.
2. Enable boxes, skeletons, and health bars.
3. Set team colors and range filters.
4. Turn on FOB and vehicle markers.
5. Save the layout as a profile.
